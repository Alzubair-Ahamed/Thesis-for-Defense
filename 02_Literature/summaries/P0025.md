## 2. Research question, task, and modality (2D mammogram FFDM/SFM vs ROI vs non-mammogram)

- **RQ / Objective:** Controlled comparison of unified (all lesions), lesion-specific (separate mass vs calcification), and hybrid ensemble training strategies under strict patient-level splitting (Abstract, p. 1; Sec. I, p. 2; Sec. II-F, p. 4).
- **Task:** Binary Benign vs. Malignant lesion classification (Sec. III-A, p. 4).
- **Modality & Paradigm:** **Pure 2D digitized screen-film mammography (SFM)** using **whole/full mammogram images** rather than ROI crops (Sec. III-A, p. 4; Sec. V-D third limitation, p. 12).

## 3. Dataset(s), provenance, and reported patient/exam/image counts

- **CBIS-DDSM (Lee et al. 2017 [16], Sec. III-A, Table 1, p. 4):**
  - **Total:** `1,428` unique patients, `2,704` full mammograms (`1,340` benign `[49.6%]`, `1,364` malignant `[50.4%]`; `1,473` masses, `1,231` calcifications).
  - **Train:** `998` patients, `1,868` images (`931` benign, `937` malignant; `1,012` masses, `856` calcifications).
  - **Validation:** `215` patients, `419` images (`205` benign, `214` malignant; `231` masses, `188` calcifications).
  - **Test:** `215` patients, `417` images (`204` benign, `213` malignant; `230` masses, `187` calcifications).
  - Exam count & CC/MLO view distribution: `not reported`. External datasets: None (`not reported`).

## 4. Diagnostic label provenance (biopsy vs BI-RADS) and Normal-case handling

- **Label Provenance:** Pathology-confirmed diagnoses (benign vs malignant) from CBIS-DDSM annotations (Sec. III-A, p. 4).
- **Normal Handling:** No Normal class (binary Benign vs Malignant only, Table 1, p. 4). `BENIGN_WITHOUT_CALLBACK` policy and exact subset filtering from full CBIS-DDSM: `not reported`.

## 5. Split level (patient vs image vs unknown) and leakage assessment

- **Split Level:** **`patient_level_verified_70_15_15`** (`~70/15/15`, `seed=42`; Sec. III-A, Table 1, p. 4; Table 2, p. 6). Zero patient overlap explicitly verified via patient ID set intersection across splits; stochastic augmentation restricted to training split; hybrid weight $\alpha^*$ and Youden threshold $\theta^*$ locked on validation only (Sec. III-B, III-D3, III-F, pp. 6–7).
- **Caveats:** Single training seed (`42`); no external validation; Strategies 2 & 3 use ground-truth lesion type (mass vs calc) to route inference images (oracle lesion-type routing, Sec. III-D2, p. 6; Sec. V-D, p. 12).

## 6. Model architectures and transfer learning initialization

- **4 Backbones (ImageNet-pretrained, end-to-end fine-tuned, Sec. III-C, Table 2, p. 6):** **ResNet50** (`25.6M`), **DenseNet121** (`8.0M`), **EfficientNet-B0** (`5.3M`), **ConvNeXt-Tiny** (`28.6M`); `384x384x3` RGB input.
- **Training:** Binary CE, Adam (`lr=1e-4`, `wd=1e-4`), ReduceLROnPlateau (patience 10, factor 0.5), max `50` ep, early stopping patience `10`, effective batch `32` (`16x2`), FP16 AMP, grad clip `<=1.0`, NVIDIA L4 (`24 GB`). Ensembles (Sec. III-D, pp. 6–7): Unified 4-CNN average, Lesion-Specific 8-CNN average, Hybrid $\alpha^*=0.4$ (val grid search).

## 7. Preprocessing and data augmentation

- **Preprocessing (Sec. III-B, pp. 4–6):** DICOM->PNG->RGB->gray -> `5x5` Gaussian blur -> Otsu threshold -> `5x5` morph close/open -> 2%-padded breast bbox -> aspect-preserving pad & resize `384x384` (`INTER_AREA`) -> **CLAHE** (`clip=4.0`, `8x8` tile, `p=1.0` all splits) -> ImageNet normalization.
- **Training-Only Augmentation (`albumentations`, Sec. III-B, p. 6):** H-flip (`0.5`), shift-scale-rotate ($\pm 6.25\%$, $\pm 10\%$, $\pm 10^\circ$, `p=0.5`), brightness/contrast ($\pm 15\%$, `p=0.5`), gamma (`[85, 115]`, `p=0.3`), Gaussian noise/blur (`p=0.2`).

## 9. Classification, calibration, and statistical metrics with exact page/table/figure locators

- **Individual Unified CNNs on Test ($n=417$, Table 3, p. 8):** ResNet50 AUC `0.739` (`0.690–0.782`), Acc `69.1%`; EfficientNet-B0 AUC `0.760` (`0.710–0.806`), Acc `69.5%`; DenseNet121 AUC `0.748` (`0.700–0.793`), Acc `68.1%`; ConvNeXt-Tiny AUC `0.747` (`0.699–0.791`), Acc `71.0%`; Mean AUC `0.748 ± 0.008` *(Fig. 3 p. 9 prints `0.749, 0.769, 0.746, 0.748`)*.
- **Lesion-Specific (Tables 4–5, p. 10):** Mass ($n=230$) best DenseNet121 `0.773` (`0.712–0.829`); Calc ($n=187$) best EfficientNet-B0 `0.751` (`0.678–0.816`).
- **Ensembles on Test ($n=417$, Tables 6–7, p. 11):** Unified AUC **`0.783`** (`0.736–0.825`), F1 `0.725`, TP `162`, FP `72`, FN `51`, TN `132`; Lesion-Specific AUC `0.756` (`0.711–0.797`); Hybrid ($\alpha^*=0.4$) AUC **`0.782`** (`0.738–0.824`), Sens `72.8%`, Spec `68.1%`, F1 `0.716`, FP `65`.
- **Fixed-Sensitivity Operating Points (Table 9, p. 11):** At `90%` sensitivity: Unified Spec `42.2%` (`118 FP`) vs Hybrid Spec `49.0%` (`104 FP`, `-11.9%` FP reduction).
- **Statistical Tests (Table 8, p. 11):** Paired **DeLong test** + stratified bootstrap 95% CIs (`B=1,000, seed=42`) + Bonferroni $\alpha=0.0167$: Hybrid vs Unified $\Delta\text{AUC}=-0.001$ (`[-0.021, +0.020]`, NS); Hybrid vs Lesion-Specific $\Delta\text{AUC}=+0.026$ (`[+0.010, +0.042]`, $p<0.001$).
- **Calibration (ECE/Brier), PR-AUC, McNemar:** `not reported`.

## 11. Author-stated limitations vs reviewer critique

- **Author-stated (Sec. V-D, pp. 11–12):** No radiologist comparison; oracle lesion-type routing; full mammograms vs ROIs; single digitized-film CBIS-DDSM cohort ($n=417$ test) without external validation; no XAI.
