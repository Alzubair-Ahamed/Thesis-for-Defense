## 1. Verified bibliographic citation and ReportRef

- **Authors:** Ines Cruchinho Garcia, Mariana Mourao, Francisco Maria Calisto, Carlos Santiago, and Jacinto Nascimento.
- **Title:** *Healthy Counterfactual Generation via Diffusion Inpainting for Mammography Classification*.
- **Venue / Year / Identifier:** *arXiv preprint*, `arXiv:2610.12147v1 [cs.CV]` (8 Oct 2026), `11` pp.
- **DOI:** `not reported` (arXiv preprint; screening `papers.csv` ID `P1433`).
- **ReportRef:** `none` (`Stage-2` High-Priority Full-Text Open-Access Verification — Modern `ConvNeXt` / `ViT` / `Mammo-CLIP` / `FPN-MIL` Benchmark on `VinDr-Mammo`).

## 2. Research question, task, and modality (2D mammogram FFDM/SFM vs ROI vs non-mammogram)

- **RQ / Objective:** Generate anatomically realistic `"healthy"` counterfactual mammograms via RePaint diffusion inpainting over annotated lesion bounding boxes on `VinDr-Mammo` and evaluate whether adding counterfactuals improves false-negative reduction (`Recall@80%Spec`) across 4 distinct classifier families (`pp. 1–5`).
- **Modality:** **Full-image 2D FFDM** (`1,520 x 912` for classifiers; `512 x 512` padded for DDPM inpainting).

## 3. Dataset(s), provenance, and reported patient/exam/image counts

- **`VinDr-Mammo` (`pp. 3–5`):** All `5,000` four-view exams (`20,000` images) following the official `16,000` train (`4,000` exams) / `4,000` test (`1,000` exams) split, plus `1,410` generated healthy counterfactual negative training images (`+13%` negative class size, `p. 5`). Reader study used `70` counterfactual + `30` real healthy (blind single radiologist, `>35` yrs exp) and `100` density/BI-RADS balanced counterfactuals (`6` radiologists, `p. 6`).

## 4. Diagnostic label provenance (biopsy vs BI-RADS) and Normal-case handling

- Uses `VinDr-Mammo` radiologist BI-RADS screening binary framing (`healthy` `BI-RADS 1` for DDPM training excluding `BI-RADS 2`; `anomalous` vs `healthy` classification across classifiers, `pp. 4–5`).

## 5. Split level (patient vs image vs unknown) and leakage assessment

- **Official `VinDr-Mammo` Split (`p. 4`):** `16,000` train (`4`-fold CV for epoch selection `3,200/fold`) evaluated strictly on the held-out `4,000`-image (`1,000`-exam) official test set (`Leakage Risk: CLEAN` internally; **zero external validation**).

## 6. Model architectures and transfer learning initialization

- **Generative Counterfactual Pipeline (`Sec. 2`, p. 3–4):** OpenAI `guided-diffusion` U-Net (`256` base channels, `512x512`) + `RePaint` masked inpainting (`500` respaced steps).
- **Four Diverse Classifier Backbones (`Sec. 3.3`, pp. 4–5):**
  1. `ConvNeXt` (ImageNet CNN)
  2. `ViT` (ImageNet Transformer)
  3. **`Mammo-CLIP`** (EfficientNet pretrained on `VinDr-Mammo`)
  4. **`FPN-MIL`** (multi-scale weakly supervised MIL, EfficientNet pretrained on `VinDr-Mammo`)
  Fine-tuned `BCE` + positive class weight, `AdamW`, `lr = 3e-4`, `bs = 8`, cosine annealing.

## 7. Preprocessing and data augmentation

- Preprocessed per `Mammo-CLIP` (`[7]`): **`1,520 x 912`** final classifier input + **CLAHE** local contrast normalization (`p. 4`).

## 8. XAI method(s), target layers, and quantitative XAI evaluation (faithfulness/sanity/localization vs visual only)

- **Zero Classifier XAI Audit (`p. 5`):** Explicitly states *"We did not perform matched-pair prediction-consistency analysis"* and computes **zero** `Grad-CAM`, `IG`, attention rollout, quantitative localization (`PG/Dice/IoU`), faithfulness (`deletion/insertion`), or `Adebayo` checks on the 4 trained classifiers (diffusion counterfactuals are used only as training data augmentation, not inference XAI!).

## 9. Classification, calibration, and statistical metrics with exact page/table/figure locators

- **Official `VinDr-Mammo` Test Performance (`Table 2`, p. 8 — Baseline vs `+CF`):**
  - `ConvNeXt`: `BalAcc 73.1 -> 73.2%`, `ROC-AUC 80.3 -> 80.2%`, `Recall@80%Spec 65.9 -> 66.5%`
  - `ViT`: `BalAcc 72.3 -> 72.7%`, `ROC-AUC 77.8 -> 78.4%`, `Recall@80%Spec 63.7 -> 65.0%`
  - **`Mammo-CLIP`**: `BalAcc 77.1 -> 77.3%`, **`ROC-AUC 84.6 -> 84.8%`**, `Recall 69.0 -> 70.7%`, `Spec 85.2 -> 83.8%`, **`Recall@80%Spec 73.7 -> 74.7%`**
  - **`FPN-MIL`**: `BalAcc 76.7 -> 76.8%`, `ROC-AUC 84.1 -> 84.0%`, `Recall 73.1 -> 75.0%`, `Spec 80.2 -> 78.6%`, `Recall@80%Spec 73.2 -> 74.5%`

- **Statistical & Calibration Gaps:** Reports **point estimates only in `Table 2`** (`zero` 95% CIs, **zero DeLong / McNemar significance tests**, multi-seed variance omitted), **zero probability calibration (`ECE`/`Brier`)**, and **zero breast-density-stratified classification AUCs** (only qualitative CF realism ratings in `Fig. 4`).

## 11. Author-stated limitations vs reviewer critique

- **Author-stated:** Inpainting realism degrades negatively with lesion area (`Fig. 4`, `p = 0.0151`); underlying `VinDr-Mammo` artifacts/contrast limits; CF augmentation trades minor specificity loss (`-1.4%` to `-4.4%`) for recall gain (`p. 8`).
- **Reviewer critique:** Crucial **modern `VinDr-Mammo` full-image baseline (`Table 2`, `1,520x912`)** proving that clean leak-free full-image classification on `VinDr-Mammo` yields **realistic AUCs `0.778–0.848`** (`ConvNeXt 0.803, ViT 0.778, FPN-MIL 0.841, Mammo-CLIP 0.846`) — exposing how far `98–99%` leaky literature claims (`P0023`) drift from reality! Simultaneously demonstrates the exact multi-gap left open for our thesis: zero external validation, zero calibration (`ECE/Brier`), zero DeLong CIs, zero XAI faithfulness/localization/Adebayo verification, and zero density-stratified classifier evaluation.

## 12. Direct comparability verdict for this study

- **`B1` (Primary Clean Full-Image `VinDr-Mammo` Baseline Comparator):** Supplies clean, leak-free `1,520x912` full-image baseline benchmarks for `ConvNeXt`, `ViT`, `Mammo-CLIP`, and `FPN-MIL` (`ROC-AUC 0.778–0.848`) and highlights the exact missing pillars (`external transfer, ECE, XAI faithfulness/Adebayo, density strata`).
