## 2. Research question, task, and modality (2D mammogram FFDM/SFM vs ROI vs non-mammogram)

- **RQ / Objective:** Mitigate mammography shortcut learning on sparse lesions by combining an `EfficientNet-B3` multi-scale backbone, local-global Transformer (`Twins-SVT/CPB`), and an end-to-end top-`k` lesion-aware evidence routing branch (`LENS`) under purely image-level supervision (`Introduction`, `Methods`).
- **Task & Modality:** **3-class screening triage** (`Normal BI-RADS 1`, `Benign BI-RADS 2`, `Recall BI-RADS 4–5`; excluding `BI-RADS 3`) on cropped high-res **2D FFDM (`1,024 x 512`)**.

## 3. Dataset(s), provenance, and reported patient/exam/image counts

- **`VinDr-Mammo` (`Table 1`, `Methods`):**
  - Starts from `5,000` exams (`20,000` images) and **excludes `BI-RADS 3`** (`930` images), leaving **`19,070` FFDM images**: `Normal (BI-RADS 1): 13,406 (70.3%)`, `Benign (BI-RADS 2): 4,676 (24.5%)`, `Recall (BI-RADS 4–5): 988 (5.2%)`.
  - Follows official disjoint split: `15,256` training (`5`-fold CV inside train picking highest val Macro-F1) and **`3,814` held-out test images** (`2,681` Normal / `935` Benign / `198` Recall). Quantitative localization subset: **`193` box-annotated test cases** (`Table 9`).

## 4. Diagnostic label provenance (biopsy vs BI-RADS) and Normal-case handling

- Uses radiologist-consensus `BI-RADS` categories (`1` Normal, `2` Benign, `4–5` Recall; `BI-RADS 3` excluded to avoid ambiguous indeterminate labels per `[44]`); lacks biopsy pathology confirmation on `VinDr-Mammo` (`P0039`).

## 5. Split level (patient vs image vs unknown) and leakage assessment

- Official `VinDr-Mammo` `80/20` patient/exam-disjoint test split + 5-fold CV strictly inside training set (`Leakage Risk: CLEAN` internally; **`no external cross-dataset validation`**).

## 6. Model architectures and transfer learning initialization

- **`LENS` Family (`T: 14.93M / 22.42G FLOPs`, `S: 26.99M / 31.51G`, `B: 48.79M / 48.56G`, `Table 2`):**
  - `EfficientNet-B3` multi-scale feature pyramid `{P3, P4, P5}` -> softmax learnable scale fusion -> rectangular `(32 x 16)` tokens -> Local-Global Transformer blocks (`8x8` window CPB + sub-sampled GSA) -> top-`k` (`k=8`) gated lesion-token refinement + auxiliary lesion head (`λ=0.4`, focal loss `γ=2`, `AdamW`, `lr=1e-4`, `wd=0.05`, `100` epochs).
- **7 Unified Baselines Re-Trained Identically (`Tables 4–6`):** `ConvNeXt-S/B`, `DINOv2-S/B`, `Swin-S/B`, and `GMIC`.

## 7. Preprocessing and data augmentation

- Breast-region cropping removing background artifacts -> resized preserving mammogram aspect ratio to **`1,024 x 512`** -> training-only rotation (`±10 deg`, `p=0.5`), Gaussian noise (`σ=0.05`, `p=0.5`), scaling (`0.9–1.1`, `p=0.3`).

## 8. XAI method(s), target layers, and quantitative XAI evaluation (faithfulness/sanity/localization vs visual only)

- **Quantitative Token-Evidence Localization (`Table 9`, `n = 193` annotated test images):**
  - `LENS-Base` overall: **`Pointing Game = 73.1%`**, **`Top-8 Hit Rate = 81.9%`**, `Top-8 IoU = 0.245`, **`Heatmap Coverage = 83.1%`**.
  - **By Finding Type:** Suspicious calcifications **`87.5%` PG** (`92.5%` Top-8 Hit), Masses **`73.8%` PG** (`0.273` IoU), Focal asymmetry `57.9%`, Architectural distortion **`42.9%` PG**.
  - **Correct vs Incorrect Stratified Audit:** Correctly classified cases (`n=140`) hit **`86.5%` PG / `0.297` IoU**, dropping sharply to **`36.5%` PG / `0.103` IoU** on misclassified cases (`n=53`).
- **Missing XAI Checks Explicitly Acknowledged (`p. 22 Limitations`):** Zero external localization validation, **zero perturbation/causal faithfulness (`Deletion/Insertion`)**, **zero `Adebayo` randomization checks**, and **zero human reader study**.

## 9. Classification, calibration, and statistical metrics with exact page/table/figure locators

- **Test Set Comparison (`Tables 4–5`, `10,000` bootstrap 95% CIs, permutation & McNemar tests):**
  - **`LENS-B`:** `Acc 85.5% [84.2, 86.7]`, **`Macro-F1 79.6% [77.7, 81.4]`** (beats `ConvNeXt-B` `p = 0.001` & all others `p < 0.001`), `MCC 0.65`, `Macro-AUC 87.6% [86.2, 89.1]`, Recall `Sens 70.7% / Spec 99.7% / PPV 92.7% / Sen@FPR10 82.8%`.
  - **`Swin-B`:** Highest **`Macro-AUC 90.2% [88.9, 91.4]`** (`Acc 80.1%, Macro-F1 75.2%, Recall Sen@FPR10 81.3%`).
  - **`ConvNeXt-B`:** `Acc 83.8%, Macro-F1 76.5%, Macro-AUC 88.4% [87.0, 89.8]`.
  - **`GMIC`:** `Acc 85.1%, Macro-F1 75.5%, Macro-AUC 87.8%` (`Recall Sens only 52.0%`).
  - **`DINOv2-B`:** `Acc 81.8%, Macro-F1 69.4%, Macro-AUC 83.7%`.
- **Calibration & Density Subgroups:** **Zero `ECE` / `Brier score` calibration metrics** and **zero BI-RADS `A–D` breast-density stratified AUCs reported** despite running on `~90%`-dense `VinDr-Mammo`!

## 11. Author-stated limitations vs reviewer critique

- **Author-stated (`Discussion`):** Single-dataset (`no external multi-vendor/country evaluation`), minority-class imbalance, omitted causal perturbation experiments (`deletion/insertion`) and reader study.
- **Reviewer critique:** Premier **2026 clean `VinDr-Mammo` hybrid CNN-Transformer baseline** showing genuine rectangular-token performance (`1024x512`, `87.6–90.2% Macro-AUC`, `73.1%` PG) alongside `10,000`-bootstrap / McNemar / permutation statistics. Crucial gaps left open for our Q1 contribution: **no external dataset generalization (`CMMD/INbreast/CBIS-DDSM`)**, **no calibration (`ECE/Brier/Temp Scaling`)**, **no `Adebayo` sanity or `Deletion/Insertion` causal faithfulness**, and **no BI-RADS density (`A–D`) fairness breakdown**.
