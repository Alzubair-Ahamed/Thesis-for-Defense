## 1. Approved XAI Method Suite (`UD16` — Mandatory Baseline + Q1 Comparators)

1. **Mandatory Baseline (`RF08`):** **`Grad-CAM`** (`Selvaraju et al., 2017`) evaluated identically across every approved model family.
2. **Adopted Q1 Spatial & Axiomatic Comparators:**
   - **`Grad-CAM++`** (`weighted higher-order positive-gradient combination for multi-focal/calcification foci`),
   - **`LayerCAM`** (`element-wise spatially positive gradient weighting on finer-grid spatial stages to improve small microcalcification localization`),
   - **`Score-CAM`** (`gradient-free perturbation confidence weighting on verified stratified test/localization subsets`),
   - **`Integrated Gradients` (`IG`, 50-step Riemann path from black-background mammogram baseline)** (`axiomatic pixel-level attribution comparator`).
3. **Negative Sanity Control:** **`Guided Backpropagation`** executed specifically in the Adebayo parameter-randomization audit (`§6`) to demonstrate that unvalidated input-gradient variants can exhibit model-independent edge detection rather than diagnostic faithfulness.
4. **Explicit Non-Adoption Rationale (`LIME / KernelSHAP`):** Standard superpixel perturbation (`LIME/SHAP`) fractures continuous mammographic parenchyma and dense calcifications along arbitrary SLIC boundaries at ~`1,000x` per-image inference latency; therefore not adopted as primary localization baselines (`Score-CAM + ROAD` cover gradient-free perturbation cleanly).

## 2. Architecture-Specific Target Convolutional Layer Policy (`Bound Per MC####`)

- Exact PyTorch/`timm` layer module strings bind deterministically when the `UD13` architecture roster closes at `STEP-022` (`candidates.csv` / `model_registry.csv`) and freeze at `G09` / `G11` — **zero post-hoc layer switching after test inspection**.
- **Binding Rules:**
  - **`Grad-CAM`, `Grad-CAM++`, `Score-CAM`:** Final `2D` spatial convolutional feature block immediately preceding global pooling (`spatial grid typically 7x7 to 16x16` depending on input resolution `UD12`: `ResNet50 layer4`, `DenseNet121 features.denseblock4`, `VGG16 features[28/30]`, `EfficientNetB0 conv_head`, `MobileNetV2 features[-1]`, `InceptionV3 Mixed_7c`; if ViT/Swin hybrid baseline adopted at `STEP-022`, bind reshaped pre-head spatial block / attention rollout explicitly).
  - **`LayerCAM`:** High-resolution penultimate spatial feature stage (`typically stride-8 or stride-16, >=28x28` at `512px` input) plus final block fusion rule locked pre-training at `STEP-022`.

---

## 3. Target Logit Convention, Upsampling & Normalization Rules

1. **Logit Convention:** Compute backpropagated gradients and forward confidence scores strictly against the **raw pre-sigmoid Malignant logit $z_{\text{mal}}$** (`or log-odds z_1 - z_0` for 2-logit heads) uniformly across all `TP`, `TN`, `FP`, and `FN` test examples — never post-sigmoid probabilities `p` (`prevents gradient vanishing near p -> 1.0`).
2. **Upsampling:** Deterministic `bilinear` interpolation (`align_corners=False`) matching exact preprocessed input dimensions `(H, W)` (`and mapped inversely back onto native mammogram space when comparing against unpadded `DS0006` / `DS0002` / `DS0005` ROI masks`).
3. **Dual Normalization Contract:**
   - **Visualization & Thresholded `IoU/Dice`:** Per-image normalized map $\tilde{M} = \frac{M - \min(M)}{\max(M) - \min(M) + \epsilon} \in [0, 1]$ after `ReLU` positive clamping ($M = \max(\text{raw}, 0)$).
   - **Energy-Based Metrics (`EBPG`, `Deletion/Insertion/ROAD` ranking):** Preserve raw non-negative activation magnitudes $M_+$ before percentile sorting so empty/near-zero maps are never inflated to `[0, 1]` contrast.

---

## 4. Zero / Collapsed Attribution Map Handling Rule

- Any heatmap satisfying $\max(M_+) - \min(M_+) \le 10^{-8}$ (`ReLU collapse / dead gradient`) MUST record `MapValidityFlag = Collapsed_ZeroMap`.
- **Anti-Cherry-Picking Invariant:** Never skip, drop, or replace a collapsed map with random tie-breaking or alternative target layers at test time. Assign `PointingGame = 0`, `EBPG = 0.0`, `IoU = 0.0`, keep the image inside the `100%` coverage denominator, and report exact `CollapsedMapRate (%)` per `(MODEL####, XAI_Method, Cohort)` inside `XAIA####`.

## 5. Quantitative Faithfulness Protocol (`UD17` — Perturbation Causality)

Evaluated across `100%` of locked test scans (for `Grad-CAM`, `Grad-CAM++`, `LayerCAM`, `IG`, and `>=100` stratified patient-balanced scans for `Score-CAM` if compute-bounded, using the exact same sample for paired cross-method comparisons):
1. **Deletion AUC (`lower = better`):** Progressively mask top-attributed pixels in **`5%` increments (`0% -> 100%`, `21` steps)** using Gaussian blur (`sigma = 15`) baseline (`plus breast-interior mean check`) and record area under raw Malignant probability $p(\text{mal})$ trajectory.
2. **Insertion AUC (`higher = better`):** Progressively reveal top-attributed pixels in `5%` increments starting from `Gaussian blur sigma = 15` baseline (`avoiding OOD sharp black-box insertion artifacts`).
3. **`ROAD` (*Remove And Debias*):** Linear neighborhood pixel imputation over `5%` deletion thresholds (`avoiding edge-ring OOD confidence artifacts induced by constant zero masking`).
4. **Random-Attribution Baseline:** Matched fixed-seed uniform random ranking mask evaluated under identical schedules to prove statistical separation above chance.

---

## 6. Adebayo Sanity Check Protocol (`UD17` — Model & Data Sensitivity)

1. **Cascading Model Parameter Randomization:** Re-initialize weights (`PyTorch reset_parameters / deterministic normal init`) top-down from classification linear layer backward through final `4` architectural stages on the trained model (`seed = 20261128`) over a stratified `N >= 100` test subset (`50 Malignant + 50 Benign/Control`).
2. **Independent Layer Randomization:** Independently randomize top FC head and final spatial conv block while keeping earlier layers fixed.
3. **Data / Label Permutation Sanity Check:** Compare converged model heatmaps against a model trained identically on randomly permuted diagnostic labels (`STEP-035`).
4. **Sanity Similarity Metrics & Failure Gate:** Compute **Spearman rank correlation $\rho$**, **SSIM**, and **HOG cosine similarity** comparing randomized vs intact heatmaps. Any XAI method preserving high similarity (`median Spearman rho > 0.30` or `median SSIM > 0.50` after full top-block randomization) MUST be flagged **`Sanity_Failed_EdgeInvariance`** (`expected for Guided Backpropagation`, disqualifying it from clinical trust claims).

## 7. ROI-Mask Localization Protocol (`UD17` — Strictly Post-Hoc Verification)

Evaluated solely on `G06`-locked `LocalizationEligible` images (`DS0006 CDD-CESM LE` VIA polygons [`657` scans], `DS0005 BMCD` `*_GT.jpg` microcalcification overlays, `DS0002 DMID` `Pixel-level annotation/*.tif` [`269` overlays]; `DS0001 MIAS` coarse circles reported strictly separately; zero native masks in `DS0003 CMMD`):
1. **Pointing Game (`PG`) & Tolerance:** Fraction of lesion images where $\arg\max M_+$ falls inside ROI mask (`0 px` exact boundary AND `15 px` native-equiv tolerance reported separately).
2. **Chance-Normalized Pointing Game (`Delta-PG`, per `P0810` & `RQ3`):** $\Delta\text{PG} = \text{PG} - \frac{\text{Area}(\text{ROI})}{\text{Area}(\text{BreastForeground})}$, correcting for varying ROI lesion sizes (`preventing large diffuse calcifications from inflating naive PG`).
3. **Energy-Based Pointing Game (`EBPG`):** $\text{EBPG} = \frac{\sum_{x \in \text{ROI}} M_+(x)}{\sum_{x \in \text{Image}} M_+(x)}$ (`exact continuous energy proportion within ground-truth mask`).
4. **Thresholded Heatmap-to-ROI `IoU` & `Dice`:** Computed at prospectively frozen binarizations: **`top-10%` saliency**, **`top-20%` saliency**, and **`0.50` normalized threshold** (`never tuned post-hoc per dataset!`).

## 8. Perturbation & Multi-Seed Explanation Stability Protocol (`UD17`)

1. **Input-Perturbation Stability:** Apply radiographically benign perturbations preserving predicted class (`contrast scale x0.98 / x1.02` and `±2 px` translation, inverting pixel shift before comparison) across `N >= 100` stratified test images; report median **SSIM** and **Spearman $\rho$**.
2. **Multi-Seed Consistency:** Across all `UD15` independent random training seeds (`>= 3` seeds) of identical architectures, compute pairwise **SSIM**, **Spearman $\rho$**, and **top-20% saliency mask IoU** on locked internal/external test images.
3. **Inter-XAI Agreement:** Report pairwise heatmap rank correlation between `Grad-CAM`, `Grad-CAM++`, `LayerCAM`, `Score-CAM`, and `Integrated Gradients`.

## 9. Bounded Blinded Radiologist / Clinical-Advisor Qualitative Rubric (`UD18`)

- Governed by [qualitative_review_rubric.md](./qualitative_review_rubric.md) (`strictly obeying RF15 non-clinical-trial boundary`):
  - **Sampling Frame:** Prospectively stratified `N = 40` de-identified test cases (`10 TP, 10 FN, 10 FP, 10 TN`) balanced across `ACR A/B vs C/D` breast density and `mass vs calcification` subtypes. Zero cherry-picking of neat cases!
