## 1. UD Reference
- **`UD05`** (blocks `G04` dataset approval at `STEP-013`; feeds `G05`, `G07`, `G12`, `G15`).

## 2. Decision Question
- Which verified public 2D mammography datasets (`from CAND0001–CAND0013`) are selected for primary internal model development (`train / val / internal test`) versus strictly independent zero-shot external validation, localization (`RQ3`), calibration (`RQ1–RQ2`), and subgroup equity/artifact sensitivity (`RQ2, RQ4`), ensuring **zero patient overlap (`RISK0002`)** and **zero label/modality conflation (`RF15`, `RISK0003`)**?

## 3. REPORT FACT (`RF`) Locators
- `RF05`: Binary 2D mammogram classification task (`Malignant` vs `Benign/Normal` track separation explicitly defined in `S07`).
- `RF08`, `RF14`: Quantitative/qualitative Grad-CAM XAI evaluation with clinical trust and generalizability checks.
- `RF15`: Strict 2D mammography (`FFDM/SFM`) scope; zero DBT, ultrasound, MRI, histopathology, tabular benchmarks, or contrast-subtracted (`CESM CM`) imaging.

### Disposition of Remaining `candidates.csv` & Local Workspace Assets
1. **`DS0004_CBIS_DDSM` (`CAND0005`):** Partial cropped/ROI download (`23.41 GB` in local `03_Datasets/raw/DS0004_CBIS_DDSM/`) was aborted in `STEP-012` prior to acquiring full mammograms (`kept untouched on local disk per Data Owner / user instruction`). Excluded from `STEP-013` QC and active model experiments.
2. **Batch B Optional Queue (`CAND0001 VinDr-Mammo`, `CAND0003 INbreast`, `CAND0010 EMBED`):** Remain `BLOCKED_PENDING_DUA_OR_CITI`. Non-blocking because `DS0003 + DS0006 + DS0005 + DS0002 + DS0001` already provide **`5` independent, geographically distributed (`China, Egypt, Cyprus, India, UK`), license-clean `CC BY` cohorts (`7,420` retained mammograms)** spanning both `FFDM` (`8b` & `12b/16b`) and `SFM` (`8b`) with polygonal/pixel lesion masks and `ACR A–D` breast density. Should `VinDr-Mammo` PhysioNet CITI clear before `STEP-021`, it can cleanly integrate as a supplementary `Track A` BI-RADS triage / multi-vendor benchmark via minor `UD05` addendum.

## 5. Tradeoffs & Rejected Alternatives
- **Rejected:** Pooling `CMMD`, `CDD-CESM`, `BMCD`, `DMID`, and `MIAS` into one blended training pool (destroys zero-shot multi-center validity `RQ2` and mixes `SFM` + `FFDM` + `BI-RADS` triage + `biopsy` truth).
- **Rejected:** Using `DMID` (`DS0002`) for internal random train/test splitting despite missing DICOM `PatientID` tags (`would leak bilateral CC/MLO views across folds`). Keeping `DMID` strictly as external held-out evaluation eliminates intra-split leakage completely.
- **Rejected:** Using `DDSM` / `Mini-DDSM` (`CAND0004/CAND0006`, mirror overlaps) or subtracted `CESM CM` images (`RF15` exclusion).

## 6. Recommendation
Approve the **`5`-cohort, zero-overlap multi-center design (`DS0003 CMMD` Primary + `DS0006 CDD-CESM LE`, `DS0005 BMCD`, `DS0002 DMID`, `DS0001 MIAS` External/Localization)** at **`G04`**, locking quarantine of the `17` discovered clone/conflict scans (`3` in `DS0002`, `6` in `DS0003`, `8` in `DS0005`) and advancing cleanly to `S07 / STEP-014` (`label & mask protocol`).
