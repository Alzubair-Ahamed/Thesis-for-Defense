## 1. UD Reference
- **`UD10`** (blocks `STEP-020` & `G07`).

## 2. Decision Question
- Which exact identity, study, bilateral-pair, and clone equivalence keys define atomic connected components, and what conservative fallback applies when `DICOM PatientID` is absent upstream (`DMID`, `MIAS`)?

## 3. REPORT FACT (`RF`) & Observed Data Evidence
- `OS §4.5`: Multi-view mammograms (`CC/MLO`), bilateral pairs, longitudinal pairs, and pixel clones must never cross partitions.
- Observed cohort structures: `DS0003 CMMD` has `1,775` `PatientID`s with `2` cross-patient pixel-clone clusters (`D1-0202<->D2-0284`, `D1-0808<->D1-1292`); `DS0006` has `326` `Patient_ID`s; `DS0005` has `100` prior/recent folders (`Normal_40<->Suspicious_16` clone cluster); `DS0001` pairs `322` PGMs into `161` odd/even `mdb` women; **`DS0002 DMID` has `0/510` `PatientID` headers** and `3` lossy clones (`IMG019/021/034`).

## 4. `PLANNING RECOMMENDATION` Options & Evidence
- **Graph Edges (`build_equivalence_graph` in [split.py](../../src/bc_xai/data/split.py)):** Connect `(DatasetID, ImageID)` nodes via: `(a)` `(DatasetID, PatientGroupID)`, `(b)` non-empty `DICOMPatientIDHash` / `DICOMStudyUIDHash`, `(c)` `ExactDupCluster` & global file `SHA256`, and `(d)` `DS0001 MIAS` sequential L/R pair (`(num-1)//2+1`).
- **Conservative Fallback for `DS0002 DMID` (`0/510 PatientID`):** Quarantine `DS0002` **`100%` into `external_test_dmid`** (`zero intra-cohort train/val/test splitting!`) so missing cross-view links can never cause internal train/test leakage.

## 5. Tradeoffs & Rejected Alternatives
- **Rejected:** Heuristic perceptual `dHash <= 4` clustering for cross-patient merges (`CMMD QC proved 142,259 distinct cross-patient breast silhouette false hits`); treating `DMID` `IMG###` scans as independent patients inside internal training splits (`unbounded CC/MLO view leakage`).

## 6. Recommendation
Ratify connected-component graph keys `(PatientGroupID, DICOMPatientIDHash, DICOMStudyUIDHash, ExactDupCluster, GlobalSHA256, MIAS_L/R_Pair)` and the `DS0002` external-only conservative isolation fallback.
